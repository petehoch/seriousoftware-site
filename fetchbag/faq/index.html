FAQ

Frequently Asked Questions

What is the difference between a QuickBag and a saved FetchBag?

QuickBag is a one-time compound search. Choose your criteria, run the search, and all matching Items will be displayed.

If you want to use that search again, save it and give it a Bag Name. It then appears as a FetchBag in the FetchBags section.

A saved FetchBag is a saved search. It does not move, copy, or own the Items it finds. Each time you open it, it shows the Items that currently match its criteria, including Items added after the FetchBag was saved.

Where is my FetchBag data stored?

By default, FetchBag stores your Items, their connections, and saved FetchBags in a local FetchBag folder in the app's internal Documents directory.

You can choose a different storage folder in Settings. If your current library contains Items, FetchBag asks whether to move the existing files or switch folders without moving them.

Referenced Documents remain in their original locations. FetchBag does not copy them into your FetchBag folder.

Does FetchBag sync between devices?

To use the same FetchBag on multiple devices, choose a storage folder available on each device, such as a folder in iCloud Drive. In FetchBag Settings on each device, select that same FetchBag folder.

Your Items, their connections, and saved FetchBags are stored in that folder and become available as iCloud Drive or your storage provider synchronizes them. FetchBag does not provide its own cloud synchronization; the default local folder is not shared between devices.

Referenced Documents are different. Each device needs permission to access the original Document outside the FetchBag folder. The first time you use it on another device, FetchBag may show Reselect Document. Select the original Document in Files to give that device access. FetchBag remembers the selection on that device.

Does FetchBag work offline?

Yes. FetchBag reads and writes Items as files in its current storage folder. If your FetchBag folder is local, it works offline normally.

If your FetchBag folder is in iCloud, Items that are already available on the device can be opened and searched offline, but new changes may not sync to other devices until the device is back online. Files that iCloud has not downloaded to the device yet may not be available offline.

What is included in the free version?

The free version of FetchBag supports up to 10 saved Items. FetchBag Pro offers unlimited Items.

What Shortcuts does FetchBag provide?

FetchBag features Search FetchBag, Add Text, and Add Document, plus actions that retrieve text, URLs, dates, and files from Items for use in other actions.

See Using FetchBag with Shortcuts for search criteria, required inputs, and examples.

What happens if a referenced Document is moved, deleted, or unavailable?

FetchBag references the original Document. Its saved title, Notes, and connections remain in FetchBag even when the original cannot be accessed.

  • Another device needs access: Use Reselect Document and select the original in Files. FetchBag remembers the selection on that device.
  • A cloud file is temporarily unavailable or downloading: Check that it is available in Files and try again. This does not mean the original was deleted.
  • The original moved or access was lost: Use Reconnect File to select the original again.
  • The original was deleted: Restore it from its storage location or a backup, then reconnect if needed. FetchBag cannot restore a Document it only references.
What happens when I delete an Item?

Deleting an Item removes it from your FetchBag library and deletes its FetchBag Item record. For Document Items that reference an original file location, FetchBag does not delete or modify the original file.

Deleting a saved FetchBag deletes only the saved search. It does not delete any of the Items that matched the search.
