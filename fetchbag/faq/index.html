FAQ

Frequently Asked Questions

What is the difference between a QuickBag and a saved FetchBag?

QuickBag is a one-time compound search. Choose your criteria, run the search, and all matching Items will be displayed.

If you want to use that search again, save it and give it a name. It then appears as a FetchBag in the FetchBags section.

A saved FetchBag is a saved search. It does not move, copy, or own the Items it finds. Each time you open it, it shows the Items that currently match its criteria, including Items added after the FetchBag was saved.

Where is my FetchBag data stored?

By default, FetchBag stores your Items and saved searches in a local FetchBag folder in the Apps internal documents directory.

You can choose a different storage folder in Settings. When you do that, FetchBag will ask if you would like the current files moved to the new location.

Does FetchBag sync between devices?

FetchBag does not have its own sync service. If you use the default folder in iCloud, iCloud handles synchronizing those files across your devices.

FetchBag itself does not control or guarantee iCloud synchronization. If you choose a different storage folder, synchronization depends on the file-syncing services available for that folder.

Does FetchBag work offline?

Yes. FetchBag reads and writes Items as files in its current storage folder. If your FetchBag folder is local, it works offline normally.

If your FetchBag folder is in iCloud, Items that are already available on the device can be opened and searched offline, but new changes may not sync to other devices until the device is back online. Files that iCloud has not downloaded to the device yet may not be available offline.

What is included in the free version?

The free version of FetchBag supports up to 10 saved Items. When you reach that limit, you can upgrade to FetchBag Pro to add more Items.

What Shortcuts does FetchBag provide?

FetchBag provides four App Shortcuts:

  • Fetch Item — Finds a saved Item by title and returns its primary saved payload, such as text, a URL, or Item details.
  • Search FetchBag — Searches FetchBag using a short query and reports the top matching Items.
  • Add Text — Adds a Text Item with a title and optional tags.
  • Add Document — Adds a Document Item with an optional title and tags.

Search FetchBag understands some useful query patterns, including Item types, simple date phrases such as "before 2025" or "since 2025," and a person's name in some queries. It is not intended to be a general conversational search.

What happens if a Document Item I added is moved or deleted?

FetchBag stores a reference to the document's original file location. If that file is moved or deleted, FetchBag marks the Item title with "(missing)" and displays it in red.

The Item's saved title, notes, and connections remain in FetchBag, but the original document cannot be opened or previewed until the file is restored.

What happens when I delete an Item?

Deleting an Item removes it from your FetchBag library and deletes its FetchBag Item record. For Document Items that reference an original file location, FetchBag does not delete or modify the original file.

Deleting a saved FetchBag deletes only the saved search. It does not delete any of the Items that matched the search.
