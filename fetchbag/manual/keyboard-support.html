Keyboard Support

Keyboard Shortcuts

FetchBag supports these shortcuts when using a hardware keyboard:

Library

  • ⌘N — New FetchBag: Create a new saved FetchBag.
  • ⌘1 — New Text: Add a Text Item.
  • ⌘2 — New Document: Add a Document Item.
  • ⌘3 — New Image: Add an Image Item.
  • ⌘4 — New Link: Add a Link Item.
  • ⇧⌘E — Edit Item: Edit the currently selected Item.
  • ⌘Delete — Delete Item: Delete the currently selected Item.
  • ⌘, — Settings: Open FetchBag Settings.

Shortcuts that require a selected Item are unavailable when no Item is selected.

Editing Items and FetchBags

  • Tab — Next Field: Move to the next text field. After the last field, focus returns to the first field.
  • ⇧Tab — Previous Field: Move to the previous text field. From the first field, focus wraps to the last field.
  • ⌘S — Save: Save the Item or FetchBag.
  • Escape — Cancel: Close the editor without saving.

QuickBag

  • Tab / ⇧Tab: Move forward or backward through the visible search fields, wrapping at either end.
  • Return — Search: Run the QuickBag search.
  • Escape — Close: Close QuickBag.
  • ⌘S — Save: Save the current QuickBag from its results screen or confirm saving from the Bag Name prompt.

FetchBag automatically scrolls the form when the next field is outside the visible area.

Standard system text-editing shortcuts—such as ⌘C, ⌘X, ⌘V, ⌘Z, and ⇧⌘Z—also work while editing text.
