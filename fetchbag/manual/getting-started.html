Getting Started with FetchBag

FetchBag is a way to store information you expect to use again. Add Text, Image, Document, and Link Items, connect them to the context you remember, then fetch the right Item when you need it.

Your FetchBag library

The main library groups your Items by type:

  • Text — multi line text snippet.
  • Documents — documents and other files you want to find again.
  • Images — photos from your photos app.
  • Links — websites and other URLs.

The library also includes a FetchBags section. A saved FetchBag is a saved filter of your Items. It does not move, copy, or own the Items it finds. Each time you open it, it shows the Items that currently match its criteria, including Items added after the FetchBag was saved.

Where FetchBag stores your Items

By default, FetchBag stores your Items and saved searches in a local FetchBag folder in the Apps internal documents directory.

You can choose a different storage folder in Settings. When you do that, FetchBag will ask if you would like the current files moved to the new location.

Add something you want to use again

Every Item has a title and can also include a date, people, places, and tags. The Item type determines the primary content you add.

Add a Text Item

Tap the Add Text button on the main screen. Enter a title and the text you want to keep. Both are required before you can save.

Text can be anything you expect to reuse. Once saved, the Item has an Email button. This will launch your default email app and use the title as the subject and the body of the email will be filled with the text.

Add a Link Item

Create a Link Item and enter a title and URL. You can also add Notes about the link. If you enter a URL without a scheme, FetchBag attempts to treat it as an HTTPS address.

Add an Image Item

Create an Image Item and choose an image from Photos. You can also add Notes about the image.

When available, FetchBag uses photo metadata to help add context automatically. It can use the image creation date as the Item date and, when GPS metadata is available, resolve the image location to a city and state.

Add a Document Item

Create a Document Item and choose a file. You can also add Notes about the document. FetchBag can use the file name as the title and the file modification date as the Item date when those values are available.

FetchBag stores a reference to the document's original file location. If the original file is later moved or deleted, the Item's saved title, Notes, and connections remain in FetchBag, but the document cannot be opened or previewed until the file is restored.

Connect an Item to what you remember

Finding something later is often easier when you remember its context rather than its exact title or filename.

FetchBag lets you connect an Item to:

  • People
  • Places
  • Date
  • Tags

People, places, and tags can be entered manually. On iOS, FetchBag can also help you choose a person from Contacts or use your current location to fill in a place. Manual entry remains available if you do not grant those permissions.

For Document, Image, and Link Items, the Notes field gives you a place for useful free-form context that does not naturally belong in People, Places, Date, or Tags. For a Text Item, the Text itself is the Item's primary content.

Find something quickly

Use the Search field in the library when you know a word or detail associated with an Item. FetchBag searches across titles, Item types, Text and Notes content, URLs, file names, people, places, and tags.

Matching Items are ranked by relevance. Title matches are weighted most heavily, followed by people and places, then tags and Item content.

Use QuickBag for a compound search

QuickBag is a one-time compound search for the times when a simple text search is not enough.

Choose one or more criteria such as Item type, Text or Notes, image or document name, URL, people, places, tags, or date. Date searches can include Items before a date, after a date, or between two dates.

Run the search and all matching Items are displayed.

If you want to use that search again, save it and give it a name. It then appears as a FetchBag in the FetchBags section.

Fetch and reuse an Item

Select an Item to open its detail view. Depending on the Item type, you can:

  • Open a Link Item in the system browser.
  • Preview an available Image Item.
  • Copy the primary content of supported Items on iOS.
  • Email a Text Item on iOS.

Use FetchBag with Shortcuts

FetchBag provides four App Shortcuts:

  • Fetch Item — finds a saved Item by title and returns its primary saved payload, such as text, a URL, or Item details.
  • Search FetchBag — searches FetchBag using a short query and reports the top matching Items.
  • Add Text — adds a Text Item with a title and optional tags.
  • Add Document — adds a Document Item with an optional title and tags.

Search FetchBag understands some useful query patterns, including Item types, simple date phrases such as "before 2025" or "since 2025," and a person's name in some queries. It is not intended to be a general conversational search.

Free and Pro

The free version of FetchBag supports up to 10 saved Items. When you reach that limit, you can upgrade to FetchBag Pro to add more Items.
