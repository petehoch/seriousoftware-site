Using FetchBag with Shortcuts

FetchBag works with Apple’s Shortcuts app, so you can add and find things without opening FetchBag and use what you find as part of larger automations.

For example, you can find a document and immediately preview or share it, or fetch reusable text and copy it to the clipboard.

Featured Shortcuts

FetchBag provides three featured actions: Search FetchBag, Add Text, and Add Document.

Search FetchBag

Search FetchBag finds matching FetchBag Items and passes the results to the next action in your shortcut.

You can use a simple free-text search or narrow the results using any combination of:

  • Item Type
  • Title
  • People
  • Places
  • Tags
  • Text or Notes
  • URL
  • Filename
  • Date Range — Any Time, Before, After, or Between

You can combine free-text Search with structured criteria. When several criteria are provided, an Item must satisfy all of them.

Leave all criteria empty to return all FetchBag Items.

Search results use the same filtering and relevance ordering as FetchBag. When several Items might match, Apple’s Choose from List action is an easy way to let the user select one before continuing the shortcut.

Add Text

Add Text creates a Text Item without opening FetchBag.

Provide:

  • Title — required
  • Text — required
  • Tags — optional

The new Item is immediately available to FetchBag and other Shortcut actions.

If a required value isn't supplied when you build the shortcut, Shortcuts will ask you for it when the shortcut runs.

The normal free-version Item limit applies when adding Items through Shortcuts.

Add Document

Add Document creates a Document Item from a document supplied by Files or another Shortcut action.

Provide:

  • Document — required
  • Title — optional; FetchBag uses the document's filename without its extension when no title is supplied
  • Tags — optional

When Shortcuts supplies an accessible file URL, FetchBag references the original Document. Changes to the original remain available through FetchBag. If Shortcuts instead supplies file data without an original file URL, FetchBag stores that supplied data with the Item; it is not a reference to an original Document.

If a supplied file URL cannot be accessed, the action may fail. It does not automatically store a copy instead.

If access to a referenced Document is unavailable, the Item's title, Notes, and connections remain in FetchBag. See Using referenced Documents on another device for access and recovery steps.

The new Item is immediately available to FetchBag and other Shortcut actions.

The normal free-version Item limit applies when adding Items through Shortcuts.

Using Items in Other Shortcut Actions

Search FetchBag, Add Text, and Add Document return FetchBag Items that can be passed to other actions in your shortcut.

FetchBag provides several actions for getting useful information from those Items.

For Document and Image Items, use Get FetchBag Item File before passing the result to an action that expects a file. Search FetchBag returns FetchBag Item entities, not the underlying Document or Image files.

For example: Search FetchBag → Choose from List → Get FetchBag Item File → Quick Look.

Get FetchBag Item Text

Get FetchBag Item Text returns a selected text value from a FetchBag Item.

Choose from:

  • Title
  • Item Type
  • Text
  • Notes
  • People
  • Places
  • Tags
  • File Name

For example, use Text to retrieve the reusable text from a Text Item, or People to retrieve the people connected to an Item.

Get FetchBag Item URL

Get FetchBag Item URL returns the URL from a Link Item as a URL that can be passed to another Shortcut action.

For example, pass it to Apple’s Open URLs action to open the link.

Get FetchBag Item Date

Get FetchBag Item Date returns the Date connected to a FetchBag Item.

Because it is returned as a Date rather than plain text, it can be passed directly to other Shortcut actions that work with dates.

Get FetchBag Item File

Get FetchBag Item File returns the actual file associated with a Document or Image Item.

The returned file can be passed to actions such as:

  • Quick Look
  • Share
  • Save File
  • Open In
  • Send Email

For externally referenced Documents, FetchBag uses the access saved on the device running the shortcut to retrieve the original file when it is available.

Using referenced Documents on another device

To use the same FetchBag on multiple devices, choose a folder available on each device, such as a folder in iCloud Drive, and select that same FetchBag folder in FetchBag Settings on every device. Your Items and connections become available as the storage provider synchronizes the folder. FetchBag does not provide its own cloud synchronization.

Access to referenced Documents is separate. If Get FetchBag Item File reports that a Document needs access on this device, open the Item in FetchBag and use Reselect Document to select the original in Files. FetchBag remembers that selection on the device. Run the shortcut again after selecting the Document.

If access has been lost, use Reconnect File in FetchBag. A cloud file may also be temporarily unavailable or still downloading; check that it is available in Files before trying again. If the original has been deleted, restore it before reconnecting. The Item's title, Notes, and connections remain in FetchBag.

Fetch Item

Fetch Item is also available as a title-matching action that returns a text result. For automations that need a Document or Image file, use Search FetchBag followed by Get FetchBag Item File.
